## Frontend task routing

For frontend work, use `frontend-task` when available. Consult Project Atlas
only when its tools are connected and its compact code, design, impact, or
memory context adds value. If Atlas is unavailable or irrelevant, continue with
the repository and relevant sources already available. Never install,
initialize, or authorize Atlas, plugins, or connectors automatically.
